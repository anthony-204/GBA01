## 30-second summary

1. **What it does:** Checks fleet vehicle starter cables and recommends a fuse size + part number.
2. **What you enter:** Machine model (dropdown) and optional fuse safety factor (default 25%).
3. **What you get:** Pass/fail checks, recommended fuse (A), GB part #, and plain-language next steps.
4. **How to run:**

   ```bash
   cd fuse-tool
   npm install
   npm run dev
   ```

   Open http://localhost:3000

5. **Status:** Functional as a **basic mine-site library tool** (37 machines pre-loaded). Manual data entry and full Excel parity are Phase 2.
